# Reading the data

```{r}
artic<-read.table("N_09_area_v2_data.txt",header=TRUE)
attach(artic)
```



# Fitting the full model

```{r}
full<-lm(extent~year+I(year^2))
```


# Fitting the reduced model

```{r}
reduced<-lm(extent~1)
```


# Is the sea-ice extent  varying with the respect to the time ?


We will consider a $F$-test

```{r}
anova(reduced,full)
```

# Conclusion

p-value indicates that time has a significant influence.
