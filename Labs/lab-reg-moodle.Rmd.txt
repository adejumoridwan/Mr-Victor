# Multiple linear model 

Syntax 

```{r eval=FALSE}
lm(y~x1+x2)
```

We want to add  a new predictor `year^2` to our simple linear regression model.

First example


```{r eval=FALSE}
brad.pitt<-year^2
fit.2<-lm(extent~year+brad.pitt)
fit.2
```
2. Second example

```{r eval=FALSE}
fit.3<-lm(extent~year+I(year^2))
fit.3
```

We plot the fitted model

```{r eval=FALSE}
plot(year,extent,pch=20,col=4)
grid()
lines(year,fitted(fit.1),col=2)
lines(year,fitted(fit.2),col=1)
legend("bottomleft",legend = c("linear","quadratic"),
col=c(2,1),lty=1)
```


We plot the residuals
```{r eval=FALSE}
par(mfrow=c(1,2))

grid()
par(mfrow=c(1,1))
```


# Properties of the residuals

1. The mean of residuals is always zero.
```{r eval=FALSE}
r<-residuals(fit.2)
mean(r)
```


**Warning:** It is a property of the estimation method.

```{r eval=FALSE}
mean(residuals(fit.1))
```

2. The  residuals are always uncorrelated with the fitted values.
```{r eval=FALSE}
yhat<-fitted(fit.2)
cor(r,yhat)
```

3. The  residuals are always uncorrelated with the predictors. 
```{r eval=FALSE}
cor(r,year)
cor(r,year^2)
```

$R^2$

```{r eval=FALSE}
ssres<-sum(r^2)
sstot<-sum((extent-mean(extent))^2)
r2<-1-ssres/sstot
r2
```

or exploiting the `summary` command

```{r eval=FALSE}
summary(fit.2)$r.squared
```

$R^2$ of the previous model
```{r eval=FALSE}
summary(fit.1)$r.squared
```







## $R^2$ is always increasing:  a simulated example

We create a new variable `z` 

```{r eval=FALSE}
set.seed(13)
n<-length(extent)
z<-4*rnorm(n)
plot(z,extent,pch=20,col=4,main="Scatteplot against a simulated variable")
grid()
```

The correlation, `cor(z,extent)`, is weak. 

We fit a model with this new variable `z` 
```{r eval=FALSE}
fit.sim<-lm(extent~year+I(year^2)+z)
```

Comarison of the $R^2$ for the different models

```{r eval=FALSE}
summary(fit.1)$r.squared
summary(fit.2)$r.squared
summary(fit.sim)$r.squared
```


# adjusted-$R^2$

```{r eval=FALSE}
summary(fit.1)$adj.r.squared
summary(fit.2)$adj.r.squared
summary(fit.sim)$adj.r.squared
```
