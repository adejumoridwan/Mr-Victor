(b) Significance of Coefficients

  • precip and slope are highly significant (both p < 2e-15), indicating strong and reliable linear associations with soil nitrogen concentration.
  • aspectS is significant at the 5% level (p ≈ 0.023), suggesting that south-facing hillsides have on average ~1.25 mg N kg⁻¹ more nitrogen than north-facing ones, after accounting for the other predictors.
  • temp is not significant (p ≈ 0.69). Its near-zero coefficient and large standard error relative to the estimate suggest that once precipitation, slope, and aspect are included, average air temperature contributes no additional explanatory power. It is a candidate for removal.

The residual diagnostics show:

  • Residuals vs Fitted: Points are scattered randomly around zero with no obvious curvature, consistent with linearity and homoscedasticity.
  • Normal Q-Q: Points follow the diagonal closely, with only minor deviation in the tails.
  • Scale-Location: The spread of standardized residuals appears roughly constant across fitted values — no strong evidence of heteroscedasticity.
  • Residuals vs Leverage: No points fall outside Cook’s distance contours; no unduly influential observations.
  • The Shapiro-Wilk test (p = 0.914) gives no evidence against normality of errors.

Overall, the residuals appear consistent with the assumption \(\varepsilon_i \sim \mathcal{N}(0, \sigma^2)\).

(d) Is This a Reasonable Model?

Yes, this appears to be a reasonable model for several reasons:

  1. The model explains ~91% of the variance in soil nitrogen (R² = 0.9075), which is a very strong fit for ecological field data.
  2. Residual diagnostics (Q-Q plot, Shapiro-Wilk) support the normality assumption.
  3. There are no severe leverage or influence issues.
  4. The signs of key coefficients are ecologically interpretable: more precipitation → more nitrogen; steeper slope → less nitrogen (likely due to leaching/erosion); south-facing aspects → slightly higher nitrogen.

However, temp is clearly non-significant and inflates model complexity without improving fit. A model without temp (see part f) is equally reasonable and more parsimonious.

(e) All 16 Models — AIC, AICc, and BIC

predictors <- c("temp", "precip", "slope", "aspect")
combos <- do.call(c, lapply(0:4, function(k) combn(predictors, k, simplify = FALSE)))

results <- data.frame()
for (i in seq_along(combos)) {
  vars <- combos[[i]]
  form <- if (length(vars) == 0) as.formula("nitrogen ~ 1") else
    as.formula(paste("nitrogen ~", paste(vars, collapse = " + ")))
  m <- lm(form, data = soil)
  n <- nrow(soil)
  k <- length(coef(m)) + 1       # parameters including sigma
  ll <- logLik(m)[1]
  aic  <- -2 * ll + 2 * k
  aicc <- aic + (2 * k * (k + 1)) / (n - k - 1)
  bic  <- -2 * ll + log(n) * k
  label <- if (length(vars) == 0) "intercept only" else paste(vars, collapse = " + ")
  results <- rbind(results, data.frame(Model = label, K = k,
                   AIC = round(aic, 2), AICc = round(aicc, 2), BIC = round(bic, 2)))
}

results[order(results$AICc), ]   # sort by AICc
