Exercise 1

a. Normal approximation to the Poisson for small numbers?

No, it is not a fair approximation for small λ. The Poisson distribution for small λ (e.g., λ = 1, 2, 3) is heavily right-skewed and discrete. The normal distribution is symmetric and continuous. The approximation only becomes reasonable when λ ≥ ~10–20.

par(mfrow = c(2, 2))

for (lambda in c(1, 3, 10, 30)) {
  x <- 0:max(20, lambda + 4*sqrt(lambda))
  pois_pmf <- dpois(x, lambda)
  norm_pdf  <- dnorm(x, mean = lambda, sd = sqrt(lambda))
  
  plot(x, pois_pmf, type = "h", col = "steelblue", lwd = 2,
       main = paste0("Poisson vs Normal (λ = ", lambda, ")"),
       xlab = "x", ylab = "Probability / Density", ylim = c(0, max(pois_pmf, norm_pdf) * 1.1))
  lines(x, norm_pdf, col = "red", lwd = 2)
  legend("topright", legend = c("Poisson", "Normal"), col = c("steelblue", "red"), lwd = 2)
}

For λ = 1 or 3 the Poisson is clearly asymmetric; by λ = 30 the curves overlap well.

b. Normal approximation to the Binomial for small numbers?

No, not for small n or p far from 0.5. The Binomial is skewed when p is far from 0.5 or n is small. A common rule of thumb requires both np ≥ 5 and n(1−p) ≥ 5.

par(mfrow = c(2, 2))

params <- list(c(5, 0.1), c(10, 0.3), c(30, 0.5), c(50, 0.5))

for (p in params) {
  n <- p[1]; prob <- p[2]
  mu  <- n * prob
  sig <- sqrt(n * prob * (1 - prob))
  x   <- 0:n
  binom_pmf <- dbinom(x, n, prob)
  norm_pdf  <- dnorm(x, mean = mu, sd = sig)
  
  plot(x, binom_pmf, type = "h", col = "steelblue", lwd = 2,
       main = paste0("Binomial vs Normal (n=", n, ", p=", prob, ")"),
       xlab = "x", ylab = "Probability / Density",
       ylim = c(0, max(binom_pmf, norm_pdf) * 1.1))
  lines(x, norm_pdf, col = "red", lwd = 2)
  legend("topright", legend = c("Binomial", "Normal"), col = c("steelblue", "red"), lwd = 2)
}

For n=5, p=0.1 the approximation is very poor; for n=50, p=0.5 it is excellent.

Exercise 2

a & b. Can Poisson and Binomial share the same mean and variance?

Yes. For a Binomial(n, p): mean = np, variance = np(1−p). For a Poisson(λ): mean = λ, variance = λ.

Setting them equal: - np = λ → p = λ/n - np(1−p) = λ → requires (1−p) = 1, i.e., p → 0 and n → ∞

So the exact match requires the Poisson limit: n → ∞, p → 0, with np = λ fixed. In practice for finite n, choose p = λ/n for any large n; the variance np(1−p) = λ(1 − λ/n) ≈ λ when n ≫ λ.

lambda <- 5
n_values <- c(10, 50, 100, 1000)

cat(sprintf("%-10s %-10s %-15s %-15s %-15s\n", "n", "p", "Binom Mean", "Binom Var", "Poisson Var"))
for (n in n_values) {
  p   <- lambda / n
  mu  <- n * p
  var <- n * p * (1 - p)
  cat(sprintf("%-10d %-10.4f %-15.4f %-15.4f %-15.4f\n", n, p, mu, var, lambda))
}

Output shows that as n grows, the Binomial variance approaches λ = 5.

Exercise 3

Memphis earthquakes: X ~ Poisson(λ = 6.5)

a. Exact probability P(X ≥ 9)

lambda <- 6.5

# P(X >= 9) = 1 - P(X <= 8)
prob_exact <- 1 - ppois(8, lambda)
cat("Exact P(X >= 9):", round(prob_exact, 6), "\n")

Result: P(X ≥ 9) ≈ 0.1762

b. Gaussian (Normal) approximation with continuity correction

For a Poisson(λ), approximate X ~ N(μ = λ, σ² = λ), i.e., N(6.5, 6.5). Apply the continuity correction: P(X ≥ 9) ≈ P(Z ≥ 8.5) under the normal.

mu  <- lambda
sig <- sqrt(lambda)

# Without continuity correction
prob_norm <- 1 - pnorm(9, mean = mu, sd = sig)
cat("Normal approx (no correction):  ", round(prob_norm, 6), "\n")

# With continuity correction
prob_norm_cc <- 1 - pnorm(8.5, mean = mu, sd = sig)
cat("Normal approx (with correction): ", round(prob_norm_cc, 6), "\n")

cat("Exact Poisson:                   ", round(prob_exact, 6), "\n")
cat("Error without correction:", round(abs(prob_norm - prob_exact), 6), "\n")
cat("Error with correction:   ", round(abs(prob_norm_cc - prob_exact), 6), "\n")

Results:

Method P(X ≥ 9)
Exact Poisson 0.17622
Normal (no correction) 0.14693
Normal (continuity corrected) 0.18673

Assessment: With λ = 6.5, the normal approximation is only moderate quality — λ is not large enough for the distribution to be sufficiently symmetric. The continuity correction improves the estimate noticeably (error ~0.010 vs ~0.029 without it), but neither is highly accurate. You’d want λ ≥ 15–20 for a reliable normal approximation.

# Visualise the comparison
x <- 0:20
plot(x, dpois(x, lambda), type = "h", col = "steelblue", lwd = 2,
     main = "Poisson(6.5) vs Normal Approximation",
     xlab = "Earthquakes per year", ylab = "Probability / Density")
curve(dnorm(x, mu, sig), add = TRUE, col = "red", lwd = 2)
abline(v = 8.5, col = "darkgreen", lty = 2, lwd = 1.5)
legend("topright", legend = c("Poisson(6.5)", "Normal(6.5, 6.5)", "Continuity cutoff (8.5)"),
       col = c("steelblue", "red", "darkgreen"), lwd = 2, lty = c(1,1,2))
